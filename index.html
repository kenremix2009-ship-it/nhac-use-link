Hướng dẫn Sử dụng 3D Character Studio & Xuất Model từ Blender 4.3

Cách nhập Model 3D (.GLB / .glTF / .VRM)
  1. Nhấn nút màu xanh Import Model ở góc trên phải hoặc kéo-thả trực tiếp file .glb, .gltf, .vrm vào giữa khung nhìn 3D.
  2. Nếu bạn có file .blend của Blender 4.3: Mở trong Blender → chọn File → Export → glTF 2.0 (.glb) rồi nhập vào đây.
  3. Hệ thống sử dụng bộ đọc nhị phân ArrayBuffer trực tiếp nên hoạt động 100% cả khi mở file HTML trực tiếp trên máy.
Phím tắt & Điều khiển Chuột
  • Chuột trái (Kéo): Xoay Camera (Orbit)
  • Chuột phải (Kéo): Dịch chuyển (Pan)
  • Con lăn chuột: Phóng to / Thu nhỏ (Zoom)
  • Phím G / R / S / W: Move / Rotate / Scale / Select
  • Phím F: Căn đối tượng đang chọn vào giữa khung
  • Phím 1 / 3 / 7: Góc nhìn Trước / Nghiêng / Trên
  • Space: Phát / Tạm dừng Animation
  • Ctrl/Cmd + S: Lưu cấu hình dự án
